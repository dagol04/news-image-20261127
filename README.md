The World Today — a newspaper front page summing up Friday 27 November 2026's world news, drawn entirely in code. Six real stories from the day: the drone strike in Kuwait, the Gaza ceasefire strain, the Thanksgiving storms in the US, UK net migration, the World Chess Championship, and the Depardieu trial — plus an "Also today" brief and a news ticker. The program is a hand-built PNG encoder with a hand-built 5×7 bitmap font; no network, no assets, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
